---

## ⛳ About The Club

**The Gaekwad Golf Club** is a living sporting monument set across the historic 500-acre private estate of **Lukshmi Vilas Palace** in Vadodara, Gujarat. Originally commissioned by **Maharaja Pratapsinhrao Gaekwad** in the 1930s and graced by royal patrons, touring pros, and world leaders, the club features:

- **Championship Parkland & Links**: 18 holes, Par 72, measuring 6,400+ yards from the championship tees.
- **Tour-Grade Surfaces**: Hybrid Bermuda fairways and lightning-fast TifDwarf putting surfaces rolling at 10.8 on the Stimpmeter.
- **Architectural Splendor**: The monumental 1890 Indo-Saracenic Lukshmi Vilas Palace (4x the size of Buckingham Palace) serves as the backdrop and target line across key fairways.
- **Grand Banquets & Heritage Venues**: 8 distinct venues including the Star of the South Ballroom, Eugenie Regal Hall, and open-air Sunset Terrace.
- **Gaekwad Golf Academy**: Powered by TrackMan 4 launch monitors, SAM PuttLab, and certified master coaches.

## ✨ Web Experience & Features

- **Light Royal Theme & Aesthetics**: Built with high-contrast luxury typography (Cinzel, Cormorant Garamond, Plus Jakarta Sans), imperial forest green (`#0A2916`), antique gold (`#8C6D23`), and luminous ivory parchment (`#FAF8F5`).
- **Interactive 18-Hole Strategic Guide**: Full hole-by-hole walkthrough with aerial views, yardages, par ratings, stroke indices, architectural notes, and caddie master tips.
- **Digital Tee-Time Reservation System**: Step-by-step interactive booking flow with format selection, player counters, live slot scheduling, transparent green fee tariffs, and printable digital voucher pass with QR validation.
- **Virtual 360° Vantage Tour**: Interactive estate viewpoints covering Hole 4 Palace Vista, Sunset Terrace, Darbar Throne Hall, and Moti Baug.
- **Banquets & Dining Suite**: Detailed showcase for 8 palace venues with capacity guides and inquiry docket generator.
- **Membership & Reciprocal Directory**: Candidacy protocols, fellowship tiers, and worldwide reciprocal club access.
- **Club Gazette & Live News**: Searchable tournament archives and dispatch reader modal.
- **Secretariat Dispatch**: Direct contact form generating official reference dockets (`GGC-SEC-XXXX`).

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/admintechofay-a11y/The-Gaekwad-Golf-Club.git

# Navigate to the project directory
cd The-Gaekwad-Golf-Club

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The app will be available at `http://localhost:5173/`.

### Build for Production

```bash
# Create optimized production build
npm run build

# Preview the production build locally
npm run preview
```
